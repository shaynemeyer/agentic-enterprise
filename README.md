# Agentic Enterprise Labs

## Dev environment

This repo includes a [devcontainer](.devcontainer/devcontainer.json) with:

- Python 3.12 (`mcr.microsoft.com/devcontainers/python:3.12-bullseye`)
- `curl`, `git`, `openssh-client`
- VS Code extensions: Python, Pylance, autoDocstring, Even Better TOML

### Usage

Open this folder in VS Code and select **Reopen in Container** (requires the
[Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)).
